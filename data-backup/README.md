# 数据备份

本目录是 wrong-notebook 全部用户数据的每日自动备份，由 main 分支的 `scripts/git-backup.mjs` 生成（每天 04:30，仅在数据有变化时提交）。

- 文件：`backup.json`，应用标准备份格式（`BACKUP_VERSION` 11，范围：全部用户）
- 与应用内导出的差异：**图片已剥离**（错题原图、试卷题目截图、识别任务/批次整页图置空），`exportedAt` 置空用于变更检测

## 恢复步骤

1. 部署实例并创建同名账户：备份不含密码，全部用户导入要求账户预先存在
2. 管理员登录应用 → 设置 → 数据导入，选择全部用户，导入 `backup.json`（等价于 `POST /api/import?all=true`）
3. 导入后各账户重置密码；注意图片类错题只剩识别文字，拍题原图无法从本备份恢复
